# Website Audit Workflow

## Purpose

Analyze public websites for positioning, CTA design, trust elements, content structure, and conversion flow.

## Steps

1. Capture homepage headline, subheadline, and primary CTA.
2. Identify target audience and core promise.
3. List trust elements such as testimonials, logos, numbers, or guarantees.
4. Map conversion path from landing to action.
5. Identify friction points.
6. Summarize reusable patterns and recommendations.

## Output

Produce a Markdown report with one section per website and a final comparison summary.
