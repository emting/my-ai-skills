# MCP Builder

引導使用者新增 MCP Server、補齊 Warp 需要的設定，並完成基本驗證。

## Included Files

- `SKILL.md`: agent 執行指引
- `manifest.json`: 機器可讀 metadata

## Typical Use Cases

- 新增 GitHub、Linear、Notion 等 MCP Server
- 補齊 MCP 設定 JSON 範本
- 驗證 Warp 端是否成功讀到工具

## Origin

- Imported from local skill: `~/.skills/mcp-builder/SKILL.md`
