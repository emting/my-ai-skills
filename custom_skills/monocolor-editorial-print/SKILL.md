# 單色／雙色印刷編輯風視覺生成 Skill｜Monocolor Editorial Print

> **一句話核心主張：限制油墨、保留紙張、讓留白有結構——做的是一張「印出來的頁面」，不是加了濾鏡的圖片。**
> 本技能移植自開源專案 `yanliudesign/mono-color-skill`（README 英文版，2026-09-01 讀取；原始 SKILL.md 與 design-system/*.json 當日無法直接抓取，內容依 README 整理），改寫為七拍格式。

## S1 觸發條件 / MOTTO
**MOTTO：** Reference is grammar, not template.（參考圖是文法，不是樣板。）每一次都重新組構主體、裁切、網格、字級層級與印刷處理。

**該叫用的情況**
- 海報：活動、派對、展覽、城市散步、概念海報
- 社群視覺：小紅書封面、公眾號／電子報頭圖、Podcast 封面、文化評論插圖
- 品牌物件：明信片、邀請卡、票券、節目單、菜單、包裝貼紙
- 出版物：書封、扉頁、章名頁、zine 內頁
- 文字視覺：文學摘句、詩、個人宣言
- 把既有照片轉成單色／雙色編輯風（人像、街景、產品、植物）

**不該叫用的情況**
- 需要全彩攝影、寫實商業修圖、3D 渲染、影視感畫面
- 需要完整品牌識別系統、Logo 設計、UI 介面設計
- 需要資訊圖表、數據視覺化（改用 data-analysis 類 Skill）
- 需要中英文長篇排版稿件（本 Skill 產出的是圖像，不是可編輯排版檔）

## S2 輸入契約
| 欄位 | 必填 | 缺少時的行為 |
|---|---|---|
| 主題／概念（一句話、一個物件、一篇文章的核心） | ✅ | **必須先問**，不得自行編造題目 |
| 確切文案（主標、副標、日期、地點、微字） | ✅（若畫面含文字） | **必須先問主標的確切字串**；其餘可留白，不得虛構品牌、贊助、網址、QR code |
| 載體與比例 | — | 預設 `3:4` |
| 是否提供照片 | — | 無照片則走「符號萃取」：以 2–4 個身份錨點與局部裁切取代完整人物 |
| 油墨指定（1 色或 2 色、指定色名） | — | 預設**受控雙色**；使用者明講「單色／monochrome／one-ink」才走純單色 |
| 時代語彙（當代／復古） | — | 預設**當代編輯風**；只有明確要求才做 vintage |
| 語言 | — | 依主標文案語言判定，不自行翻譯 |

> **提問規則**：只缺「主題」或「確切主標文字」時才停下來問，其餘一律用預設值補齊並在配方中標明「（預設）」。不要一次問超過兩個問題。

## S3 執行步驟
### 步驟 1：讀輸入，判定四件事
判定 **主體（subject）／意圖（intent）／文字（words）／影像角色（image role）**。影像角色四選一：主導畫面、局部證物、重複物件陣列、無影像（純文字頁）。

### 步驟 2：選版面家族（layout family）
| 家族 | 適用 | 特徵 |
|---|---|---|
| Image 影像主導 | 人像、街景、旅行 | 大面積網點影像＋單一大字＋角落微字 |
| Specimen 標本頁 | 植物、器物、田野筆記 | 置中或偏移的單一物件＋檔案式標註 |
| Declaration 宣言頁 | 詩句、摘句、口號 | 無影像，超大字級＋大量留白 |
| Object field 物件陣列 | 產品、包裝、系列封面 | 重複物件成陣，留一塊空區給標題 |
| Overprint 套印 | 城市、運動、能量感主題 | 兩版在局部交疊，交疊處產生深色 |
| Journal 手記 | 旅行、日記、明信片系列 | 固定網格＋手寫式註記，逐張變裁切 |
| Cover 封面 | 書封、zine、Podcast | 明確標題區塊＋單一視覺事件 |

### 步驟 3：指派油墨版（plates）
預設**受控雙色**：主版佔印刷面積 **70–85%**，副版佔 **15–30%**，且副版必須有**具體任務**（日期、標註、指定物件、套印交疊處）。明確要求單色時只用一版。**紙張不是第三色；兩版交疊產生的深色也不算第三色。**

| 模式 | 說明 |
|---|---|
| Pure one-ink | 純單版，靠網點濃淡建立層次 |
| Chromatic + black | 彩色主版＋黑／碳色副版 |
| Complementary duotone | 互補雙色，冷暖對抗 |
| Overprint duotone | 刻意讓兩版交疊出第三層深色 |

### 步驟 4：組版面
- 非對稱編輯網格，**可見空白紙面佔 25–55%**
- 每頁只設定**一個大膽焦點事件**：超大字、極端裁切、單一巨大細節、集中套印、或異常尺度關係
- 其餘區域用紙面、淡網、稀疏功能性字體「放鬆」——放鬆是**能量不均**，不是整體降低強度
- 加入**一個刻意的破壞**（斷裂線、越界物件、未收邊）
- 字級：最大文字是微字的 **5–12 倍**，最多 **3 種字體聲音**（襯線編輯體＋窄體無襯線／等寬機能體）

### 步驟 5：加入受控的印刷偶然性
偶然性只發生在**複製層**，不動構圖、不降低文字可讀性：
- 當代作品：選 **0–2** 個克制效果
- 質感／復古／檔案感作品：選 **2–3** 個有界效果
- 可選效果：油墨濃淡不均、乾邊斷墨、網點漂移、套印錯位、一道斷裂筆勢

### 步驟 6：編譯 production prompt 並生成
先把所有決策寫成**配方清單（recipe manifest）**，再編譯成一段英文 prompt 交給圖像生成工具。**先鎖配方再生圖**，才能在重試時保持一致。

### 步驟 7：自檢七條規則（未過就重做，不交付）
1. 油墨不超過兩版，主副版比例與分工正確
2. 紙張可見，不是數位單色濾鏡
3. 以機械複製為主：網點、顆粒、爆亮、積墨、輕微套印偏移
4. 留白 25–55%，且服務於焦點事件
5. 字級張力：5–12 倍落差，≤3 種字體聲音
6. 提供的人／物／場景**身份可辨**
7. 與任何參考圖至少更動 **4 項結構變數**（主體、裁切、網格、字級層級、印刷處理）

## S4 安全閘門
**風險等級：🟡 對外輸出需人審。** 任何要對外發布的成品，發布前必須人工過目。

**絕不輸出**
- 虛構的品牌名、贊助商、獎項、網址、QR code、電話、票價、報名連結
- 未經確認的活動日期、地點、主辦單位——**日期與地點只能照抄使用者提供的字串**
- 重建特定既有海報、模仿在世設計師簽名風格、複製藝術家標記
- 真實人物的可辨識肖像用於未授權的商業或政治宣傳素材

**必須停下來交人的情況**
- 使用者提供的照片含第三人肖像且用途為對外商業發布 → 提醒確認肖像授權
- 文案涉及金額、優惠、名額、法規聲明 → 原字照放，不改寫、不補齊
- 要求超過兩版油墨、或要求做成全彩 → 明說這已脫離本 Skill，詢問是否改走一般視覺生成

**不得自行承諾**：印刷可行性、實際印刷色準、特別色編號對應（Pantone 對色需由印刷廠確認）。

## S5 輸出格式
一次執行固定回傳三段：

**① 配方清單（Recipe）**
| 項目 | 值 |
|---|---|
| 印刷模式 | Pure one-ink／Chromatic + black／Complementary duotone／Overprint duotone |
| 油墨 | 主版（70–85%）＋副版（15–30%）與各自任務 |
| 紙張 | Neutral White／Cool Gray／Pale Beige |
| 比例 | 預設 3:4 |
| 版面家族 | 七選一 |
| 字體配對 | ≤3 種聲音，標明最大／最小字級倍率 |
| 印刷處理 | halftone／risograph grain／cyanotype／photocopy breakup ＋ 偶然性效果數量 |
| 留白 | %（25–55） |
| 焦點事件 | 一句話 |
| 原創性變更 | 相對參考更動的 ≥4 項結構變數 |

**② Production prompt**：一段可直接貼進圖像生成工具的**英文** prompt（含比例、紙色、油墨十六進位、網點處理、留白比例、確切文案字串、negative 條件）。

**③ 圖像**：有生成工具時附上成品；沒有工具時，只交付 prompt 並明說「本次無法生成圖像」。

## S6 失敗處理（Stop Rules）
| 狀況 | 處理 |
|---|---|
| 沒有主題或主標文字 | 停下來問，最多問兩題；不自行擬題 |
| 使用者指定的顏色互相衝突或超過兩色 | 保留使用者最重視的兩色，說明取捨；不偷偷加第三版 |
| 照片解析度太低／主體不明 | 改走符號萃取（2–4 個身份錨點），並告知取捨 |
| 生成結果變成「彩色照片套濾鏡」 | 判定失敗，加強 halftone／紙張可見度後重生，不交付 |
| 文字在圖像中被生壞（錯字、亂碼） | 降低文字量、放大字級重生；仍失敗則交付「無文字版本＋文字另行排版」的建議 |
| 要求複製某張參考海報 | 拒絕重建，改為抽取其視覺文法並更動 ≥4 項結構變數 |
| 無圖像生成工具 | 只交付 prompt＋配方，明確標示限制 |

## 標準執行契約

### 觸發與輸入

使用者明確要求「單色／雙色印刷編輯風視覺生成 Skill｜Monocolor Editorial Print」的核心任務，或輸入與本技能描述高度相符時才啟用。先確認目標、受眾、上下文、資料來源、授權、限制條件與希望的輸出格式；未提供的資訊不得自行補成事實。

### 執行順序

1. 盤點輸入、授權、敏感資料與可能的外部依賴，先列出缺口。
2. 依上方技能流程逐步處理，將事實、推論、假設與建議分開。
3. 產出可直接審閱的結果，列出引用、未驗證事項、風險與人工決策節點。
4. 執行輸出前檢查，確認沒有虛構證據、洩漏敏感資料或超出使用者範圍的動作。

## 輸出契約

至少提供：

- **結果或草稿**：依使用者要求產出分析、策略、腳本、內容、清單或計畫。
- **假設與限制**：明確標示資料不足、未驗證推論與適用範圍。
- **驗證紀錄**：列出使用的來源、檢查方式、驗收條件與尚待確認事項。
- **風險與下一步**：指出人工核准點、低成本驗證方式與可恢復的後續行動。

## 安全與人工核准

目前風險等級：**high**。需要人工確認。本匯入版本為 `instruction_only`，不代表已授權任何外部連接或寫入適配器。

- 先確認任務目標、輸入來源、使用授權、範圍與輸出格式；缺少關鍵資訊時先列出假設並提出最少必要問題。
- 不得捏造事實、數據、案例、評價、客戶反饋、媒體報導、認證或研究來源；無法驗證的內容必須標示為假設或待驗證。
- 只使用使用者提供或明確授權的內容；不得繞過登入、CAPTCHA、付費牆、存取控制或第三方服務限制。
- 外部服務一律採唯讀或草稿模式；發送、發佈、建立、更新、刪除、部署、交易、預算變更與權限變更前必須取得明確人工批准。
- 對個人、客戶、學生、財務、合約或私有資料採資料最小化；輸出前遮罩識別資訊，避免複製原始敏感資料。
- 涉及外部資料時記錄來源、擷取時間與查證限制；將可觀察事實、推論與建議分開呈現。
- 本技能只提供分析、草稿與驗證建議；涉及高影響決策或外部操作時，必須由適當的人員在執行前覆核。

- 不得用於未授權存取、憑證收集、冒充他人、垃圾訊息、操縱或規避平台政策。
- 不得把未經授權的第三方內容、個資或機密資料重新發布到公開服務。

## 停止條件

若使用授權、資料來源、範圍、關鍵數字、身份或外部操作權限無法確認，立即停止高影響部分並回報缺口。若發現來源互相矛盾、任務目標漂移、敏感資料暴露、輸出無法驗證或操作不可恢復，保留已完成的安全分析，暫停後續動作並要求人工判斷。

## 關聯技能

本技能與 無 有功能相近或可互補的技能；選擇時以使用者明確需求、資料來源與權限邊界為準，不要平行重複執行相同的高影響操作。
