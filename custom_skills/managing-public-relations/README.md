# Managing Public Relations／公關品牌與危機處理

## 定位

協助企業、品牌或個人建立公關策略、品牌訊息、利益關係人管理、媒體應對、PESO 媒體組合與危機處理流程。

## 使用情境

- 想提升品牌知名度、信任感、投資吸引力或合作機會。
- 需要設計企業公關、B2B 公關、媒體訪談或品牌故事。
- 遇到負面新聞、客訴、社群炎上或危機事件。
- 想建立 CIS、CSR、PESO 與利益關係人溝通。

## 不適用情境

- 使用者想隱瞞重大事實或操弄媒體。
- 危機涉及法律責任時，仍需律師與專業公關同步協作。

## 食譜式目標

| 項目 | 定義 |
| --- | --- |
| 輸入 | 品牌背景、事件、受眾、媒體、風險 |
| 輸出 | 公關策略、訊息架構、媒體策略、危機 SOP |
| 數量 | 3 個核心訊息、3 階段危機處理 |
| 格式 | 表格 + 聲明草稿 + Q&A |
| 驗收 | 能對內一致、對外清楚、危機可控 |

## 核心流程

1. 確認目標：知名度、信任、投資、合作、危機修復。
2. 定義受眾：消費者、投資人、員工、媒體、政府、供應商。
3. 統一核心訊息：三大重點，不分平台保持一致。
4. 選擇媒體組合：Paid、Earned、Shared、Owned。
5. 建立品牌拼圖：人物、故事、標誌、儀式、承諾、信仰、成就。
6. 媒體訪談準備：記者背景、艱難問題、案例與數據。
7. 危機三階段：預防、控制、修復。

## 固定輸出

```markdown
# 公關品牌與危機處理方案

## 1. 公關目標
## 2. 核心訊息
## 3. 媒體策略
## 4. 危機處理
## 5. 對外聲明草稿
## 6. 媒體 Q&A
```

## 0/1 測試

| 測試 | 通過條件 |
| --- | --- |
| 受眾明確 | 至少列出 3 類利害關係人 |
| 訊息一致 | 有 3 個核心訊息 |
| 證據存在 | 每個訊息有案例、數據、事實或標記需補證據 |
| 危機時限 | 有 24 小時內行動 |
| 內外一致 | 對內說法與對外說法不矛盾 |
