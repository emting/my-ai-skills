# Making Decisions／決策類 Skill

## 定位

協助使用者把模糊問題、選項與權衡條件整理成可判斷、可比較、可執行的決策流程。此 skill 不只列優缺點，還要依使用者目標給出推薦方案，並把高不確定決策轉成低成本驗證。

## 使用情境

當使用者面臨選擇、規劃、取捨、優先級排序或腦力激盪後需要收斂時啟用。

適用任務包含：

- 多方案比較。
- 創業方向選擇。
- 工具或技術選型。
- 是否投入某個專案。
- 優先級排序。
- 風險評估。
- 腦力激盪後收斂成決策。
- CLI 工具與 AI 工作流規劃。

## 主要目標

1. 釐清決策問題：把模糊選擇改寫成清楚的決策句。
2. 列出候選方案：補齊可比較選項與維持現狀選項。
3. 建立評估準則：用目標、限制、成本、風險、回報與時間比較。
4. 找出推薦方案：不是只平均比較，而是依使用者目標做判斷。
5. 轉成下一步實驗：對高不確定決策，先設計低成本驗證。

## 決策流程

1. 重述決策問題。
2. 列出方案，包含維持現狀／延後決策與小規模測試方案。
3. 建立評估矩陣。
4. 將不確定性分成可查資料、可測試假設、可監控風險、價值取捨。
5. 給出推薦方案、主要風險、反方觀點、低成本驗證與下一步行動。

## 固定輸出

```markdown
## 決策摘要
## 方案比較
## 不確定性與假設
## 驗證計畫
## 反方觀點與風險
```

## 品質標準

- 不只列優缺點，要給明確建議。
- 不確定時，優先設計小實驗。
- 不忽略維持現狀與延後決策選項。
- 高風險決策要列反方觀點。
- 建議必須對應使用者目標，而不是泛用最佳解。
