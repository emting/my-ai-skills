# 商業模式九宮格診斷 Skill

> **定位**：用商業模式九宮格診斷一個事業、產品、個人品牌或專案是否具備可持續性，並找出價值主張、客群、通路、關鍵資源、成本與收益之間的斷點。

## 使用情境
- 想盤點一個新事業、服務、課程、內容產品或顧問案。
- 商業模式說不清楚，收入與成本無法對上。
- 想從價值主張反推客群、通路、活動、資源與夥伴。
- 需要判斷北極星指標是否真的連到營收。

## 不適用情境
- 只需要短期活動企劃，不需要長期商業模式。
- 沒有任何收益流或成本資訊。

## 食譜式目標
| 項目 | 定義 |
|---|---|
| 輸入 | 事業描述、產品、客群、收入方式、成本、資源 |
| 輸出 | 九宮格診斷、斷點、北極星指標、修正建議 |
| 數量 | 9 格逐格檢視（資料不足的格子標「資料不足－需確認」）+ 最多 3 個優先修正 |
| 格式 | 九宮格表格 + 診斷清單 |
| 驗收 | 能判斷是否可持續、哪裡最脆弱 |

## 九宮格
1. 價值主張。
2. 目標客群。
3. 通路。
4. 客戶關係。
5. 收益流。
6. 成本結構。
7. 關鍵活動。
8. 關鍵資源。
9. 關鍵夥伴。

## 核心流程
1. 先確認收益流與成本結構是否能活下來。
2. 回到價值主張：你到底幫誰創造什麼改變？
3. 檢查目標客群是否足夠明確。
4. 檢查通路是否能穩定接觸客戶。
5. 檢查客戶關係是否能促成回購、推薦或留存。
6. 檢查關鍵活動是否真的支撐價值主張。
7. 檢查關鍵資源是否具備反脆弱性。
8. 檢查關鍵夥伴是否可替代。
9. 設定能連到收益的北極星指標。

## 0/1 測試
| 測試 | 通過條件 |
|---|---|
| 九格完整 | 9 格都已檢視；每格標示「有證據／資料不足／待確認」 |
| 收益清楚 | 收益流可被計算 |
| 成本清楚 | 成本與費用有初步拆分 |
| 客群明確 | 能描述具體客群 |
| 指標連錢 | 北極星指標與收入有直覺連結 |

## Opus 5 世代模型校準
### 資料不足的格子寧可留白（本 Skill 最大風險）
九宮格是固定九格，模型容易**用合理推測把空格填滿**。規則：使用者沒提供的格子一律標「資料不足－需確認」並列出要問什麼，不要寫出看起來很像答案的推測。**一個誠實的空格比九個填滿的格有用。**

### 0/1 測試是交付規格，不是模型自檢
五項測試保留，但定位是**你驗收這份診斷用的**。不要在提示詞中追加「輸出前逐項自我檢查五項測試」，新模型已內建自我修正，疊加只拉高成本，反而鼓勵它把格子填滿以「通過測試」。

### 斷點盤點要兩段式
不要下「只指出最致命的斷點」。新世代模型會照字面執行，把你還沒意識到的中度問題先刷掉。正確做法：第一輪九格逐格全量標出問題，第二輪再排出第 5 節的三個優先修正。

### 輸出長度
沒問題的模組在第 2 節表格裡一行帶過即可，篇幅集中在脆弱點與優先修正。**「三個優先修正」是上限不是配額**：真的只有一個關鍵斷點就寫一個，不要湊三個。

### 範圍鎖定
使用者丟一個事業就診斷那個事業。若視角拉到整間公司或整個產業會有不同結論，用一句話指出並問要不要擴大，不要自行把單一產品診斷寫成集團級戰略報告。

## 啟用提示詞
請啟用「商業模式九宮格診斷 Skill」。任務：用九宮格診斷以下事業或產品，找出商業模式斷點、北極星指標與優先修正項。

## 標準執行契約

### 觸發與輸入

使用者明確要求此主題，或輸入與本技能描述高度相符時才啟用。先確認目標、受眾、上下文、資料來源、限制條件與希望的輸出格式；未提供的資訊不得自行補成事實。

### 執行順序

1. 盤點輸入與授權，標記缺口、敏感資料與可能的外部依賴。
2. 依本技能的核心流程逐步處理，將事實、推論、假設與建議分開。
3. 產出可直接審閱的結果，並列出引用、未驗證事項、風險與需要人工決策的節點。
4. 執行輸出前檢查，確認沒有虛構證據、洩漏敏感資料或超出使用者範圍的動作。

### 輸出契約

至少提供：

- **結果或草稿**：依使用者要求產出分析、策略、腳本、內容、清單或計畫。
- **假設與限制**：明確標示資料不足、未驗證推論與適用範圍。
- **驗證紀錄**：列出使用的來源、檢查方式或尚待確認的項目。
- **風險與下一步**：指出人工核准點、低成本驗證方式與可恢復的後續行動。

### 安全與人工核准

目前風險等級：**high**。需要人工確認。

- 先確認任務目標、輸入來源、使用授權、範圍與輸出格式；缺少關鍵資訊時先列出假設並提出最少必要問題。
- 不得捏造事實、數據、案例、評價、客戶反饋、媒體報導、認證或研究來源；無法驗證的內容必須標示為假設或待驗證。
- 只使用使用者提供或明確授權的內容；不得繞過登入、CAPTCHA、付費牆、存取控制或第三方服務限制。
- 外部服務一律採唯讀或草稿模式；發送、發佈、建立、更新、刪除、部署、交易、預算變更與權限變更前必須取得明確人工批准。
- 對個人、客戶、學生、財務、合約或私有資料採資料最小化；輸出前遮罩識別資訊，避免複製原始敏感資料。
- 此技能只提供分析、草稿與驗證建議，不代表法律、財務、醫療、投資或營運承諾；高風險決策須由合適的人員覆核。

### 禁止用途

- 不得用於未授權存取、憑證收集、冒充他人、垃圾訊息、操縱或規避平台政策。
- 不得把未經授權的第三方內容、個資或機密資料重新發布到公開服務。
- 不得在沒有明確批准、完整上下文與可回溯驗證的情況下執行高影響外部操作。

### 停止條件

若使用授權、資料來源、範圍、關鍵數字、身份或外部操作權限無法確認，先停止執行高影響部分並回報缺口。若發現來源互相矛盾、任務目標漂移、敏感資料暴露或輸出無法驗證，保留已完成的安全分析，暫停後續動作並要求人工判斷。
