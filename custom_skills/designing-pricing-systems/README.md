# Designing Pricing Systems／定價策略與成交系統

## 定位

協助使用者設計價格、報價情境、成交流程與回購系統，判斷該採短期高溢價、長期品牌、封閉式報價或公開標準品策略。

## 使用情境

- 不知道產品該賣高價還是合理價。
- 客戶嫌貴，但其實可能是不懂價值。
- 想設計顧問、課程、保健品、餐廳、實體店或社群商品的成交系統。
- 想用 CRM、回訪、折價券、返利、試用或社群證據提升成交。

## 不適用情境

- 涉及違法誇大、醫療療效保證、金融投資保證。
- 使用者無法交付承諾價值。

## 食譜式目標

| 項目 | 定義 |
| --- | --- |
| 輸入 | 產品、成本、毛利、客群、通路、競品價格 |
| 輸出 | 定價策略、報價系統、成交流程、回購設計 |
| 數量 | 至少 2 種價格方案、1 條成交路徑 |
| 格式 | 表格 + 流程 |
| 驗收 | 價格能說明價值，流程能推動成交 |

## 核心判斷

### 兩種定價模型

- **短期燒肝型**：高廣告費、高溢價、快速收割。
- **長期品牌型**：合理價格、穩定信任、長期回購。

### 報價系統

- **封閉式報價**：非標準品、顧問、房仲、客製服務；客戶對價值敏感。
- **開放式報價**：標準品、日用品、公開競品；客戶對價格敏感。

### 成交系統

1. 建立信任證據。
2. 放大痛點與結果。
3. 提供試用或案例。
4. 設計限時或分層方案。
5. 建立回購週期。
6. 用 CRM 提醒回訪。
7. 設計推薦或返利。

## 固定輸出

```markdown
# 定價策略與成交系統

## 1. 產品摘要
## 2. 定價策略
## 3. 報價系統
## 4. 成交流程
## 5. 回購與推薦
```

## 0/1 測試

| 測試 | 通過條件 |
| --- | --- |
| 成本可見 | 知道成本與毛利 |
| 價值可說 | 能說明為何值這個價 |
| 報價場景 | 判斷封閉或開放 |
| 成交路徑 | 有接觸到成交的步驟 |
| 回購設計 | 有回訪或推薦機制 |
