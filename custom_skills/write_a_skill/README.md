# Write a Skill

建立新的 agent skill，並補齊觸發條件、檔案結構與必要附帶資源。

## Included Files

- `SKILL.md`: agent 執行指引
- `manifest.json`: 機器可讀 metadata

## Typical Use Cases

- 根據新需求建立 skill
- 重新設計現有 skill 的 description 與觸發條件
- 產出 `SKILL.md`、範例與結構建議

## Origin

- Imported from local skill: `~/.skills/write-a-skill/SKILL.md`
