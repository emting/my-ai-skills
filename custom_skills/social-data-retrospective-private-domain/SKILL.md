# 社群數據覆盤與私域經營 Skill

> **定位**：用數據驅動社群內容與私域經營，建立規劃、創作、發佈、覆盤、電子報、名單磁鐵與公域轉私域的完整流程。

## 使用情境
- 經營 IG、FB、Threads、YouTube、電子報、LINE 社群或個人品牌。
- 發文靠靈感，缺少穩定節奏與數據覆盤。
- 想把公域流量導入電子報或私域名單。
- 想建立內容配比、開信率、觸及率、儲存率、分享率追蹤。

## 不適用情境
- 使用者只想短期爆紅，不願長期穩定產出與紀錄。
- 內容涉及醫療、保健或投資但不願做法規查核。

## 名單與隱私閘門
加入電子報／LINE 私域名單前須有明確 opt-in、用途告知、保存期限與退訂／刪除方式；個資最小化。未同意者不得匯入名單。

## 食譜式目標
| 項目 | 定義 |
|---|---|
| 輸入 | 帳號目標、TA、平台、內容類型、數據 |
| 輸出 | 內容週期表、數據覆盤表、私域轉換方案 |
| 數量 | 60% 出圈內容 + 40% 養粉內容 |
| 格式 | 表格 + SOP + 指標 |
| 驗收 | 能每週自己跟自己比，調整內容策略 |

## 核心流程
1. **帳號定位**：品牌導向或創作導向。
2. **TA 與平台**：先決定對誰說，再決定在哪裡說。
3. **內容規劃**：出圈、養粉、信任、轉換、互動。
4. **創作 SOP**：資料收集、法規查核、製作、排版、手機閱讀檢查。
5. **發佈時機**：依後台上線時間與 TA 作息。
6. **數據紀錄**：發文後半小時、一天、七天。
7. **週覆盤**：只跟自己的平均比，不盲目比較他人。
8. **私域導流**：北極星 CTA 導入電子報或名單。
9. **名單清理**：90 天無互動者清理。

## 0/1 測試
| 測試 | 通過條件 |
|---|---|
| TA 明確 | 能描述具體受眾 |
| 節奏固定 | 有週期性發佈計畫 |
| 數據可記 | 有固定欄位 |
| 配比存在 | 出圈與養粉有比例 |
| 私域 CTA | 有明確導流目的地 |

## Opus 5 世代模型校準
### 0/1 測試的定位
上方 0/1 測試是**方案規格的驗收標準，給人檢查用**，保留。但不要在啟用提示詞中追加「輸出前請逐項自我檢查這五項」。

### 輸出長度
固定輸出格式是欄位清單，不是最低篇幅要求。**沒有真實數據時，數據追蹤表直接留空並說明需要什麼欄位，絕不要用示範數字填滿**——覆盤表被填入虛構數字是這類 Skill 最危險的失效模式。

### 範圍鎖定
使用者只要覆盤就給覆盤，不要自動附贈完整內容規劃與私域設計。若判斷問題其實在定位或 TA，用一句話指出並問是否要往下做。

### 診斷訊號用兩段式
不要下「只挑最重要的問題」。先全量列出數據中的異常訊號，再依「對北極星 CTA 的影響」做第二輪排序。

### 內容語氣用正面示範
要電子報或貼文的風格時，直接附上你滿意的舊作當示範，比列一串「不要怎樣寫」有效。

## 標準執行契約

### 觸發與輸入

使用者明確要求此主題，或輸入與本技能描述高度相符時才啟用。先確認目標、受眾、上下文、資料來源、限制條件與希望的輸出格式；未提供的資訊不得自行補成事實。

### 執行順序

1. 盤點輸入與授權，標記缺口、敏感資料與可能的外部依賴。
2. 依本技能的核心流程逐步處理，將事實、推論、假設與建議分開。
3. 產出可直接審閱的結果，並列出引用、未驗證事項、風險與需要人工決策的節點。
4. 執行輸出前檢查，確認沒有虛構證據、洩漏敏感資料或超出使用者範圍的動作。

### 輸出契約

至少提供：

- **結果或草稿**：依使用者要求產出分析、策略、腳本、內容、清單或計畫。
- **假設與限制**：明確標示資料不足、未驗證推論與適用範圍。
- **驗證紀錄**：列出使用的來源、檢查方式或尚待確認的項目。
- **風險與下一步**：指出人工核准點、低成本驗證方式與可恢復的後續行動。

### 安全與人工核准

目前風險等級：**high**。需要人工確認。

- 先確認任務目標、輸入來源、使用授權、範圍與輸出格式；缺少關鍵資訊時先列出假設並提出最少必要問題。
- 不得捏造事實、數據、案例、評價、客戶反饋、媒體報導、認證或研究來源；無法驗證的內容必須標示為假設或待驗證。
- 只使用使用者提供或明確授權的內容；不得繞過登入、CAPTCHA、付費牆、存取控制或第三方服務限制。
- 外部服務一律採唯讀或草稿模式；發送、發佈、建立、更新、刪除、部署、交易、預算變更與權限變更前必須取得明確人工批准。
- 對個人、客戶、學生、財務、合約或私有資料採資料最小化；輸出前遮罩識別資訊，避免複製原始敏感資料。
- 此技能只提供分析、草稿與驗證建議，不代表法律、財務、醫療、投資或營運承諾；高風險決策須由合適的人員覆核。

### 禁止用途

- 不得用於未授權存取、憑證收集、冒充他人、垃圾訊息、操縱或規避平台政策。
- 不得把未經授權的第三方內容、個資或機密資料重新發布到公開服務。
- 不得在沒有明確批准、完整上下文與可回溯驗證的情況下執行高影響外部操作。

### 停止條件

若使用授權、資料來源、範圍、關鍵數字、身份或外部操作權限無法確認，先停止執行高影響部分並回報缺口。若發現來源互相矛盾、任務目標漂移、敏感資料暴露或輸出無法驗證，保留已完成的安全分析，暫停後續動作並要求人工判斷。
