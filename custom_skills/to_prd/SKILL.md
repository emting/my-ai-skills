# To PRD Skill

## Purpose

將對話脈絡與程式碼理解綜合為 PRD 文件，並保留實作決策、測試決策與範圍界線。

## When to Use

適用於使用者提到以下需求：

- `PRD`
- `產品需求文件`
- `generate a spec`
- 想把目前討論正式化成文件

## Workflow

1. 先讀對話與相關程式碼，理解目前問題、限制與既有行為。
2. 找出會被影響的核心模組、邊界條件與可測試行為。
3. 以 PRD 模板整理問題陳述、解決方案、用戶故事、實作決策與測試決策。
4. 依使用者要求輸出到對話、指定檔案，或準備成 issue 內容。

## Output Template

```markdown
## 問題陳述

## 解決方案

## 用戶故事

## 實作決策

## 測試決策

## 範圍之外

## 補充說明
```

## Output Options

- 直接在對話中輸出 Markdown
- 寫入指定文件路徑
- 整理成可貼到 issue 的內容

## Safety Notes

- 不要憑空捏造需求來源。
- 不要把容易過時的具體檔案路徑硬寫進 PRD 主體。
- 若需要建立 issue 或寫檔，先確認輸出位置。

## 標準執行契約

### 觸發與輸入

僅在使用者需求與本技能描述相符時啟用。先確認目標、受眾、上下文、資料來源、限制與輸出格式；未提供的資訊不得自行補成事實。

### 執行順序

1. 盤點輸入、授權、敏感資料與外部依賴。
2. 依技能核心流程處理，分開標示事實、推論、假設與建議。
3. 產出可審閱結果，列出來源、未驗證事項、風險與人工決策點。
4. 輸出前檢查範圍、引用、敏感資料與高影響操作。

## 輸出契約

- **prd**：依技能規格提供

## 安全與人工核准

目前風險等級：**low**。

- 不得捏造資料或來源。
- 外部服務採唯讀或草稿模式；寫入、發佈、部署與不可逆操作前須人工批准。

## 停止條件

若授權、來源、範圍、關鍵數字、身份或外部操作權限無法確認，停止高影響部分並回報缺口；若發現矛盾、敏感資料暴露或輸出無法驗證，暫停後續動作並要求人工判斷。

## 關聯技能

本技能與 目前沒有經人工確認的直接關聯技能 有功能相近或可互補的關係；選擇時以任務範圍、資料來源與權限邊界為準。
