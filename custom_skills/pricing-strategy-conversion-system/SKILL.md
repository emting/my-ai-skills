# 定價策略與成交系統 Skill

> **定位**：協助使用者設計價格、報價情境、成交流程與回購系統，判斷該採短期高溢價、長期品牌、封閉式報價或公開標準品策略。

## 使用情境
- 不知道產品該賣高價還是合理價。
- 客戶嫌貴，但其實可能是不懂價值。
- 想設計顧問、課程、保健品、餐廳、實體店或社群商品的成交系統。
- 想用 CRM、回訪、折價券、返利、試用或社群證據提升成交。

## 不適用情境
- 涉及違法誇大、醫療療效保證、金融投資保證。
- 使用者無法交付承諾價值。

## 食譜式目標
| 項目 | 定義 |
|---|---|
| 輸入 | 產品、成本、毛利、客群、通路、競品價格 |
| 輸出 | 定價策略、報價系統、成交流程、回購設計 |
| 數量 | 至少 2 種價格方案（下限不是配額）、1 條成交路徑 |
| 格式 | 表格 + 流程 |
| 驗收 | 價格能說明價值，流程能推動成交 |

## 核心判斷
### 兩種定價模型
- **短期燒肝型**：高廣告費、高溢價、快速收割。
- **長期品牌型**：合理價格、穩定信任、長期回購。

### 報價系統
- **封閉式報價**：非標準品、顧問、房仲、客製服務；客戶對價值敏感。
- **開放式報價**：標準品、日用品、公開競品；客戶對價格敏感。

### 成交系統
1. 建立信任證據。
2. 放大痛點與結果。
3. 提供試用或案例。
4. 設計限時或分層方案。
5. 建立回購週期。
6. 用 CRM 提醒回訪。
7. 設計推薦或返利。

## 真實性閘門
限時、名額、見證與成效主張必須真實且有證據：不得虛構名額、期限、見證或成效；促銷與回報主張須可核實並經人工覆核。

## Opus 5 世代模型校準
### 不適用情境是安全邊界，一律保留
「違法誇大、醫療療效保證、金融投資保證」與「無法交付承諾價值」這兩條是紅線，不是可卸除的品質補強。

### 不要用推測數字填定價表（本 Skill 最大風險）
定價表有價格欄，而模型很容易在沒有成本與競品資料時直接寫出一個看起來很具體的數字。規則：**沒有成本或競品價格時，價格欄寫「需成本資料」，不要給數字。** 若確實要給參考區間，必須同時寫出推算依據與假設。定價寫錯的代價是真金。

### 數量是下限不是配額
「至少 2 種價格方案」是避免只給單一選項，不是要你湊方案。若情境上只有兩種合理結構，就給兩種並說明為何不需要第三種。成交流程也一樣，不要把七步都強填。

### 診斷要兩段式
不要下「只指出最關鍵的定價問題」。先把成本、價值說明、報價場景、成交路徑、回購設計五個面向**全量**標出缺口，再排優先序。實務上「客戶嫌貴」很少是單一原因造成的。

### 話術用正面示範
要求「不要用壓迫式話術」不如直接給一句範例。輸出成交話術時，附一行你自己過去用過、有效的真實句子當語感基準。

### 輸出長度
固定輸出格式是欄位清單，不是最低篇幅。不要附送定價理論、心理定價學術背景或行業概述，除非你問了。

## 標準執行契約

### 觸發與輸入

使用者明確要求此主題，或輸入與本技能描述高度相符時才啟用。先確認目標、受眾、上下文、資料來源、限制條件與希望的輸出格式；未提供的資訊不得自行補成事實。

### 執行順序

1. 盤點輸入與授權，標記缺口、敏感資料與可能的外部依賴。
2. 依本技能的核心流程逐步處理，將事實、推論、假設與建議分開。
3. 產出可直接審閱的結果，並列出引用、未驗證事項、風險與需要人工決策的節點。
4. 執行輸出前檢查，確認沒有虛構證據、洩漏敏感資料或超出使用者範圍的動作。

### 輸出契約

至少提供：

- **結果或草稿**：依使用者要求產出分析、策略、腳本、內容、清單或計畫。
- **假設與限制**：明確標示資料不足、未驗證推論與適用範圍。
- **驗證紀錄**：列出使用的來源、檢查方式或尚待確認的項目。
- **風險與下一步**：指出人工核准點、低成本驗證方式與可恢復的後續行動。

### 安全與人工核准

目前風險等級：**medium**。預設可先產出分析或草稿，但仍不得代替使用者做外部高影響決策。

- 先確認任務目標、輸入來源、使用授權、範圍與輸出格式；缺少關鍵資訊時先列出假設並提出最少必要問題。
- 不得捏造事實、數據、案例、評價、客戶反饋、媒體報導、認證或研究來源；無法驗證的內容必須標示為假設或待驗證。
- 只使用使用者提供或明確授權的內容；不得繞過登入、CAPTCHA、付費牆、存取控制或第三方服務限制。
- 外部服務一律採唯讀或草稿模式；發送、發佈、建立、更新、刪除、部署、交易、預算變更與權限變更前必須取得明確人工批准。

### 禁止用途

- 不得用於未授權存取、憑證收集、冒充他人、垃圾訊息、操縱或規避平台政策。
- 不得把未經授權的第三方內容、個資或機密資料重新發布到公開服務。

### 停止條件

若使用授權、資料來源、範圍、關鍵數字、身份或外部操作權限無法確認，先停止執行高影響部分並回報缺口。若發現來源互相矛盾、任務目標漂移、敏感資料暴露或輸出無法驗證，保留已完成的安全分析，暫停後續動作並要求人工判斷。
